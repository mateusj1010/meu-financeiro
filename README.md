# Meu Financeiro v1.4 — correção de cadastro de cartões e assinaturas

Corrigido o formulário de assinaturas ausente, que interrompia a inicialização do JavaScript de cartões e deixava os seletores vazios.

## Publicação

1. Exporte backup JSON no aplicativo antes de atualizar.
2. Envie todos os arquivos desta pasta para a raiz do repositório GitHub Pages, substituindo os anteriores.
3. Aguarde a publicação, atualize a página no Safari e, se usar o ícone instalado, feche e reabra o aplicativo.
4. Na aba Cartões, toque em **+ Cartão**, cadastre e salve; depois registre a compra.

Os dados permanecem no armazenamento local do navegador, desde que o endereço/origem seja o mesmo. Faça backups frequentes.
